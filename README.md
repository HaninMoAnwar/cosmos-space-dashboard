# Cosmos - Space Dashboard

A visually stunning, responsive space exploration and analytics dashboard layout. This project focuses on high-fidelity UI/UX engineering, utilizing a modern dark-themed aesthetics combined with strict component organization.

Deployed Preview: [Live Demo](https://haninmoanwar.github.io/cosmos-space-dashboard/)

---

## Key Features

- **Advanced Grid Architecture:** A multi-column widget dashboard built with fluid CSS layouts that automatically scale across viewports.
- **Dark Mode Aesthetics:** High-contrast design focusing on clear element separation, soft shadows, and clean neon typographic hierarchy.
- **Component Separation:** Modular layout setup handling multiple card designs (e.g., flight analytics, system status graphs, exploration cards).
- **Pixel-Perfect Responsive Styling:** Seamless transitions from heavy content desktop screens down to mobile layouts.

---

## Built With

- **HTML5:** Semantic architecture (`<main>`, `<aside>`, `<section>`, `<article>`) for enhanced accessibility.
- **CSS3:** Advanced flexbox properties, layout grid systems, dynamic custom hover transitions, and variable management.
